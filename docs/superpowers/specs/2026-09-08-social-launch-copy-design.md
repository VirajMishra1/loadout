# Loadout Social Launch Copy Design

## Goal

Introduce Loadout on X and LinkedIn in Viraj Mishra's established voice: start
with a concrete problem, explain what he built in plain language, support it
with specific facts, and end with a direct invitation to try or contribute.

## Positioning

Loadout is the package manager for AI coding agent extensions. The launch
should lead with the fragmented setup problem, then distinguish Loadout through
project-aware optimization and durable Claude Code/Codex collaboration.

Avoid unsupported claims such as "the first ever," "revolutionary," or
guarantees of virality. Prefer demonstrable facts from the repository and the
recorded product demo.

## X Structure

The main post contains the native video, GitHub link, product hook, and the
strongest feature summary. It must fit the standard X character limit. A short
reply thread then explains:

1. Why agent-extension discovery and setup are broken.
2. How Maximum and Optimize avoid prompt pollution.
3. How Handoff carries source context and verification criteria.
4. How Coord uses ownership and contracts for parallel work.
5. How Discuss produces a bounded Claude Code/Codex decision.
6. The local, preview-first trust model and install command.

## LinkedIn Structure

Use one longer post in Viraj's problem → evidence → product → invitation
pattern. Include concrete repository facts, readable feature bullets, the demo,
the install command, GitHub link, and a request for feedback, issues, stars, and
contributions. Do not copy the X thread verbatim.

## Editorial Process

Codex writes the fact-checked draft. Claude receives one compact editorial turn
to challenge the hook, pacing, and authenticity. Codex then produces the final
paste-ready versions while retaining only claims supported by the repository.
